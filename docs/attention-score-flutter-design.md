# Flutter 注意力分数曲线方案

本轮先完成 Flutter，用户确认实际效果后再同步 Python 和 C# 示例。

## 展示

- 在现有“波形 / 频谱 / 信号”视图旁增加“注意力分数”独立视图。
- 顶部显示当前分数（保留一位小数，满分 100）和状态；下方显示趋势曲线。
- 纵轴固定 0–100；横轴按 SDK 结果时间戳显示相对时间；最多保留最近 200 个结果。
- 每个完整的两秒窗口产生一个结果。初始显示等待数据，不能把等待状态显示为有效零分。
- 正常结果与伪迹保持点使用不同颜色，并用文字说明保持状态；缺失窗口不跨空缺连接曲线。
- 切换视图持续收集并保留历史；停止后保留本轮曲线供查看，再次开始或更换数据源时清空。
- 错误或数据源断开时明确显示状态，避免把旧分数呈现为仍在更新。

## 数据与生命周期

使用 Rust 已有的 `ProcessedStream::attention_score`，通过正式 C ABI 和 Dart 绑定提供结果。当前这两层尚未暴露此指标，因此本轮包括最小必要的接口、生命周期和测试支持，不在示例内复制评分算法。

注意力独立消费所选 EEG 流的全部通道，使用未添加波形滤波器的独立处理分支。通道下拉框只影响已有视图，不改变全通道注意力分数。启动失败回滚已创建资源，停止和退出释放新增的订阅与处理分支。

## 方案取舍

推荐新增独立分数视图，复用现有 Flutter CustomPainter 绘制方式，无需新增图表依赖。放进已有信号视图会压缩曲线空间，也会混淆既有频带比值和新分数。复用旧 `attentionIndex` 虽然省去绑定工作，但与 Rust 新评分不一致，因此不采用。

以上布局、200 点历史和停止后保留曲线为本轮确认的设计。Python 和 C# 示例不在本轮实现范围；新增 ABI 涉及跨语言兼容性检查，按 Axon 仓库要求执行。

方案于 2026-11-18 经用户确认。实际预览时发现原有 BCI100 协议模拟器持续触发幅值伪迹判定，因此实现时增加 SDK 自定义 EEG 模拟器选项供正常曲线预览，保留原有数据源与评分规则。

## 验证

覆盖等待状态、正常结果、伪迹保持、错误与断开、切页历史保留以及停止重启隔离。运行 Flutter analyze/test 和 Windows 构建，使用原生模拟器验证收分与曲线；新增 ABI/Dart 接口按 Axon 测试契约执行必要测试及 workspace 检查。记录实际验证结果和未覆盖的平台。
